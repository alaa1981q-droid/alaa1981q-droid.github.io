## تطبيق إدارة المدرسة الأهلية (`madrasa/`)
Built 2026-11-27/28 for the owner's FRIEND's school: «مدرسة الأوائل الابتدائية الأهلية» (Iraq, 3-floor building, school buses). The owner manages it and asks for all changes; the friend only uses it.
- Live link (give this to users): https://alaa1981q-droid.github.io/madrasa/ — GitHub Pages from `main`. Push to `main` (owner approved publishing there; commit on the session branch then `git push origin <branch>:main`).
- Files: `madrasa/index.html` (whole app, plain JS, no build), `sw.js` (offline cache — bump `CACHE` "madrasa-vN" on EVERY change), `manifest.json`, `icon-192/512.png`, `school.jpg` (the school photo; the owner's photo had «جمعة مباركة» text removed by inpainting), `vendor/firebase-{app,auth,database}-compat.js` (10.14.1, copied from usool-deeni).
- `.dev/` (ignored by Pages/Jekyll): `fbmock.js` = Firebase compat mock for Playwright (serve it in place of vendor/firebase-app-compat.js, empty the other two; login password in mock = "pass1234"; `__setOnline(false)` to test offline); `madrasa-claude-artifact.html` = the older claude.ai artifact copy (https://claude.ai/artifact/4ibzNV99DuqpWMYfod4idU, uses the artifact `db`, no login). The live app is the main product now; the artifact copy is optional/legacy (owner may not need it; its link was set to "anyone with the link" — remind him it holds data).
- Cloud: Firebase project `awael-school-339fc` (in the OWNER's Google account, separate from usool-deeni). Realtime Database europe-west1 `https://awael-school-339fc-default-rtdb.europe-west1.firebasedatabase.app`, all data under `/school/{collection}/{docId}`. Rules: `school` read/write only `auth != null`. Auth: Email/Password only, **sign-up disabled** and delete disabled in Auth → Settings → User actions, so only accounts the owner creates in the console can log in. Account: `awael@school.com` (password known only to the owner/friend — never ask for it). New users / password resets: console → Authentication → Users.
- Sync design (index.html "cloud sync"): offline-first. localStorage `school_ledger_v1` holds everything; every `put()` stamps `_t`, marks `school_dirty_v1`, pushes the doc; deletes are tombstones `{_del,_t}` (`school_tomb_v1`). On login a whole-tree listener merges per document (newer `_t` wins; dirty local kept and re-pushed). First login on a device with local data asks upload vs start fresh. Pill «☁️ محفوظ بالسحابة / ⏳ يرفع / 📴 بلا إنترنت».
- Collections (COLS): `classes` (docs g1a..g6b, + `gx` graduates-with-debt), `staff`, `expenses`, `income` (صندوق الوارد), `cfg` (main: name, y0, sm, start, year, seq receipt counter, carry, lastBk), `archive` (y<year>: closed years, graduates, expenses, staffPays, income).
- Features (owner's requests, in order): 6 grades × sections أ/ب; class fee applies to every student; per-student discounted fee; 10 payment slots with running remainder; class treasury (only grows) vs school treasury (minus salaries, advances, expenses; plus income box); late = 4+ months since last payment (or registration); receipts as canvas PNG with amount in Arabic words, numbered, reprints stamped «نسخة مكررة», void instead of delete («ملغى» + reason); receipts archive; student statement + family statement (siblings = same parent phone); staff (teachers/workers) monthly salaries over the 12 school months, advances (سلفة, paid now, deducted from a chosen month) and deductions; general expenses; income box (donations etc. → school treasury only); daily/monthly/yearly reports + CSV + print (print only in the live app); search everywhere (any part of name/father/parent/phone, Arabic letter variants); late list with WhatsApp reminders (wa.me 964…); bus fees + other fees as separate payment categories; end-of-year results ناجح/راسب and «🎓 السنة الجديدة» rollover (pass → next grade same section, 6th pass → graduates archive, unpaid balance carried as `prev`, treasury carried over); graduates archive; PIN lock; backups (JSON download/share/restore); 3D buttons everywhere; light theme only (forced, phones in dark mode looked bad); Cairo font for headings. v23 (owner): every numbered receipt prints TWO copies on a quarter-A4 each (4 per sheet; `drawR(o,tk,lab,W)`, `printQ` with named page `@page rq` margin 0): GREEN «نسخة ولي الأمر» (or `o.who`, e.g. نسخة المستلم/المسلِّم) for the customer + BLUE «نسخة المدرسة · للإدارة والتدقيق» kept for the auditors; both show amount, remainder, date. Save/share sends only the customer copy. Statements (no='—') stay single.
